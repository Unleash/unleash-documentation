# Unleash v8.2.0

## Project-level release templates

You can now create [release templates at the project level](/concepts/release-templates#create-a-project-level-release-template), in addition to creating them globally. Project-level templates are available only within the project they belong to, so teams can manage the templates for their own projects, while global templates remain available across the whole instance.

## In-app notifications for access requests

When someone signs up for [Unleash Cloud](/support/availability#plans) with an email domain that belongs to your existing instance, they can request access to it. Admins are now notified of new requests directly in the Admin UI, in addition to email. Click **View request** to open the **Users** page, where you can see all pending requests.

## New in Unleash page for Open Source

The **New in Unleash** page is now also available in [Unleash Open Source](/support/availability#plans). It shows the latest capabilities added to Unleash and indicates which of them are Enterprise features. From the page, you can get started with a feature, read more in the documentation, request access to beta features, and see what we are working on next. You can find it in the **Help & Resources** menu in the top navigation.

## Filter flags by creator

The flags overview now includes a [Created by filter](/concepts/search-operators#filter-feature-flags), so you can filter flags by the user who created them.

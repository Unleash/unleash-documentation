# Unleash v8.2.0

## Project-level release templates

You can now create [release templates at the project level](/concepts/release-templates#create-a-project-level-release-template), in addition to creating them globally. Project-level templates are available only within the project they belong to, so teams can manage the templates for their own projects, while global templates remain available across the whole instance.

## In-app notifications for access requests

When someone signs up for Unleash with an email domain that belongs to your existing instance, they can [request access](/concepts/public-signup#access-requests) to it. Admins are now notified of new requests directly in the Admin UI, in addition to email. Click **View request** to open the **Users** page, where you can see all pending requests.

## Reworked New in Unleash page

We reworked the **New in Unleash** page, available from the **Help & Resources** menu in the top navigation. It now indicates which features are Enterprise features, and lets you get started with a feature, read more in the documentation, request access to beta features, and see what we are working on next.

## Filter flags by creator

The flags overview now includes a [Created by filter](/concepts/search-operators#filter-feature-flags), so you can filter flags by the user who created them.

Build is the hands-on course in the [Unleash Learning Lab](/learning-lab/introduction). The full course is hosted in the Learning Lab. This page gives you an overview before you begin.

Complete this course to earn the **FeatureOps Practitioner** certificate.

## Who it's for

Developers, architects, and engineers who want to put feature management into practice. The course spans several modules, starting with your first feature flag, so you can go as deep as your role needs.

## What you'll learn

- Create your first feature flag
- Target specific user segments
- Automate releases that respond to production signals
- Run real experiments
- Keep services resilient during failures

## Start the course

[Go to Build in the Unleash Learning Lab](https://learning.getunleash.io/program/build) to begin.

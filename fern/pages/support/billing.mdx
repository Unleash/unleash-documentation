## What you pay for

Unleash Enterprise bills on two dimensions only: **seats** and, on Unleash Cloud, **API traffic above the included allowance**. Nothing else is metered.

### Seats

A seat is a user account in your Unleash instance. Seats are billed at a flat monthly rate per seat, so your cost is a function of how many people have access, not how much they use Unleash.

### API traffic

On Unleash Cloud, the Pay-As-You-Go plan includes 53 million API requests per month. Requests beyond that are billed at $5 per additional million. Enterprise traffic allowances are agreed in your contract.

API requests are generated by your SDKs communicating with Unleash, not by your end users interacting with your application. This distinction matters for forecasting:

- **Backend SDKs** fetch the flag configuration for their token's scope, cache it in memory, and evaluate flags locally. Evaluating a flag does not call Unleash. A service evaluating a flag a million times per second generates no additional API traffic.
- **Frontend SDKs** either call the [Frontend API](/concepts/front-end-api) or, more commonly at scale, an [Unleash Edge](/unleash-edge) instance, which absorbs client traffic and refreshes from the upstream Unleash server on its own schedule.
- **Polling frequency** drives volume. SDKs refresh every 15 seconds by default, which you can tune per SDK.

Your monthly request volume is therefore roughly the number of connected SDK instances multiplied by their poll frequency, plus periodic metrics posts.

**Worked example.** 200 backend SDK instances polling at the 15-second default make 4 requests per minute each, or about 173,000 requests per instance per month. Across 200 instances that is approximately 34.6 million requests per month, within the included 53 million allowance. Doubling the poll interval to 30 seconds halves it.

Sustained high traffic against the Unleash API is also subject to the [Fair Use Policy](https://www.getunleash.io/fair-use-policy). Short spikes are accommodated; sustained volume is best served by [Unleash Edge](/unleash-edge).

## What is not metered

Unleash does not bill on any of the following, on any paid plan:

- Monthly active users (MAU) on client-side applications
- Flag evaluations
- Number of feature flags, within [resource limits](/concepts/resource-limits)
- Number of projects or environments, within [resource limits](/concepts/resource-limits)
- Service connections
- Number of SDKs or supported languages
- Environments used for development or testing

Because flag evaluation is not metered, there is no cost incentive to limit how many flags you create or how often you evaluate them. Putting every change behind a flag does not increase your bill.

- Access logs
- IP-based restrictions

Real-time streaming via Enterprise Edge is currently in early access.

## Self-hosted billing

Self-hosted Enterprise deployments are billed on the same per-seat basis as Unleash Cloud, with a 5-seat minimum. You run the infrastructure; Unleash provides the Enterprise build and a license key. See [License keys](/deploy/license-keys) for how to install and rotate one.

Self-hosting removes the Unleash Cloud API traffic allowance, because traffic goes to your own servers. It does not remove the cost of running the service. Operating a highly available Unleash installation to a 99.99% target typically costs \$50,000 to \$200,000 per year in infrastructure and engineering time, and each additional Edge location adds roughly $15,000 per year. Compare that against the per-seat cost of Unleash Cloud when choosing a deployment model.

## Enterprise pricing

Unleash does not publish Enterprise contract prices. Enterprise agreements are quoted per customer because the price depends on variables that differ substantially between organizations:

- Number of seats
- Deployment model: Unleash Cloud, self-hosted, or hybrid
- API traffic volume and the number of Edge regions required
- Support tier and response-time requirements
- Add-ons such as private instances, access logs, and IP restrictions
- Data residency requirements

If you need a firm number, [contact sales](https://www.getunleash.io/plans/enterprise). To size a proposal accurately, have your average daily frontend traffic, average session duration, and the number of application instances or Kubernetes pods that will connect to Unleash.

The [Pay-As-You-Go plan](https://www.getunleash.io/pricing) is priced publicly at $75 per seat per month and requires no contract, so you can determine your cost for a self-service deployment without contacting us.

## Frequently asked questions

<AccordionGroup>
<Accordion title="Does Unleash charge per monthly active user (MAU)?">
No. Unleash bills per seat, where a seat is a user of Unleash itself, not a user of your application. Client-side MAU is unlimited on all paid plans. Your bill does not change when your application's traffic grows.
</Accordion>

<Accordion title="Am I billed per flag evaluation?">
No. Backend SDKs fetch the flag configuration and evaluate flags locally in memory, so evaluations never reach Unleash and are never billed. Only SDK communication with the Unleash API counts toward your API traffic allowance.
</Accordion>

<Accordion title="What happens if I exceed the included API requests?">
On Pay-As-You-Go with Unleash Cloud, requests above the included 53 million per month are billed at $5 per additional million. If you consistently exceed the allowance, [Unleash Edge](/unleash-edge) reduces upstream traffic by absorbing SDK requests, and Enterprise contracts can include a higher allowance.
</Accordion>

<Accordion title="Is Unleash free?">
Unleash Open Source is free and has no seat limit. It gives you the core feature set and is well suited to evaluation and small-scale deployments, with a limit of 1 project and 2 environments. It does not include SSO, SCIM, role-based access control beyond basic roles, change request approval workflows, or a support SLA. See the [full comparison](/support/oss-comparison).

Running Unleash Open Source is free to license but not free to operate. Budget for the infrastructure, upgrades, and on-call coverage you take on.
</Accordion>

<Accordion title="Can I self-host and still get Enterprise features?">
Yes. Enterprise is available self-hosted, hybrid, or on Unleash Cloud, at the same per-seat price, with a 5-seat minimum for self-hosted. Self-hosting is common among customers with data residency or regulatory requirements, because flag evaluation and end-user context stay entirely within your infrastructure. See [hosting options](/deploy/hosting-options).
</Accordion>

<Accordion title="Do I need a seat for everyone who needs to see a flag?">
Anyone who signs in to Unleash needs a seat. In practice, teams get the most value when developers have full visibility rather than routing changes through a small number of licensed users, and [change requests](/concepts/change-requests) provide four-eyes approval so broad access does not mean uncontrolled access.

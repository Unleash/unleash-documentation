Unleash offers both an open-source (OSS) version and an Enterprise version.

[Unleash OSS](https://github.com/Unleash/unleash) is a great way to explore Unleash and experiment with feature flags. It gives you the core feature set of Unleash, but is designed for small-scale deployments with a limited number of server instances and direct SDK connections.

For production workloads, we recommend [Unleash Enterprise](https://www.getunleash.io/pricing). With our Enterprise plans, you have access to the full feature set, including higher resource limits, advanced governance, automation, observability, integrations for identity and compliance, and access to [Unleash Edge](/unleash-edge) for scalable SDK traffic.

Unleash Enterprise is suitable regardless of your team size, from small teams just getting started to large organizations running feature flags across thousands of services. It is designed to scale with you so you only pay for what you need, with flexible plan options from monthly pay-as-you-go to annual contracts, and flexible deployment options from [self-hosted](/guides/scaling-unleash#self-hosting-unleash-designing-for-high-availability) to [hybrid](/guides/scaling-unleash#choosing-the-right-deployment-option) to fully managed cloud.

This page highlights the key differences between Unleash OSS and Unleash Enterprise. If you already run Unleash OSS and want to move to Unleash Enterprise, see [Migrating from Unleash Open Source to Unleash Enterprise](/guides/migrate-from-open-source). For current prices and plan options, see [Upgrade to Unleash Enterprise](https://www.getunleash.io/upgrade-unleash).

## Licensing

Unleash OSS and Unleash Enterprise are distributed under different licenses.

| Component | OSS | Enterprise |
|-------------|-----|-------------|
| Source code in the [Unleash GitHub repository](https://github.com/Unleash/unleash) | AGPLv3 from v8.0.0 onwards, Apache 2.0 in earlier versions | Commercial license |

| Official Docker images | Apache 2.0 | Commercial license |

For what the licenses mean for your deployment, see the [frequently asked questions](#frequently-asked-questions).

## Move from Unleash OSS to Unleash Enterprise

You can move an existing Unleash OSS instance to Unleash Enterprise without changing your application code:

- To keep hosting Unleash yourself, switch to the Enterprise Docker image and add a [license key](/deploy/license-keys). Your database, users, API tokens, and SDK connections stay in place.
- To move to Unleash Cloud, set up a new instance, import your flags, and reconnect your SDKs.

For step-by-step instructions for both paths, see [Migrating from Unleash Open Source to Unleash Enterprise](/guides/migrate-from-open-source). To start a trial or request a quote, see [Upgrade to Unleash Enterprise](https://www.getunleash.io/upgrade-unleash).

## Frequently asked questions

<AccordionGroup>
  <Accordion title="Which license applies to Unleash OSS?">
    From v8.0.0 onwards, the source code in the [Unleash GitHub repository](https://github.com/Unleash/unleash) and the [`unleash-server` npm package](https://www.npmjs.com/package/unleash-server) are licensed under the GNU Affero General Public License v3 (AGPLv3). Earlier versions are licensed under Apache 2.0. The official open-source Docker images remain under Apache 2.0. For the background, see [Evolving our open source commitment](https://www.getunleash.io/blog/unleash-moving-to-agplv3).
  </Accordion>
  <Accordion title="Does the move to AGPLv3 affect me if I run the official Docker image?">
    No. The official open-source Docker images remain under Apache 2.0, so running a pre-built Unleash container without modifying the source is unaffected.
  </Accordion>
  <Accordion title="When does AGPLv3 apply to me?">
    AGPLv3 applies if you modify the Unleash source and make it available to users over a network, for example as a public or commercial SaaS. In that case, you make your modified source available under the same license, or contact us for a commercial license.
  </Accordion>
  <Accordion title="Does the license change affect the SDKs in my applications?">
    No. Unleash [SDKs](/sdks) keep their open-source licenses, Apache 2.0 or MIT depending on the SDK, on both Unleash OSS and Unleash Enterprise.
  </Accordion>
  <Accordion title="Does the license change affect Unleash Enterprise or Unleash Cloud?">
    No. Unleash Enterprise is covered by the Unleash commercial license on every hosting model, including Unleash Cloud. Your deployment, terms, and obligations are unchanged.
  </Accordion>
  <Accordion title="Do I need to move to Unleash Enterprise because of the license change?">
    It depends on how you use Unleash OSS:

    - If you run the official Docker image or the unmodified source, you can keep running Unleash OSS as before.
    - If you modify the Unleash source and make it available to users over a network, AGPLv3 requires you to make your modified source available under the same license. To discuss a commercial license instead, [contact us](https://www.getunleash.io/plans/enterprise).
    - If your organization has a policy on which open-source licenses it can use, check whether AGPLv3 is permitted. Unleash Enterprise is covered by a commercial license instead.

    To move to Unleash Enterprise, see [Migrating from Unleash Open Source to Unleash Enterprise](/guides/migrate-from-open-source).
  </Accordion>
  <Accordion title="Do I need to upgrade to v8 to keep using Unleash OSS?">
    The license change does not require you to upgrade. Versions earlier than v8.0.0 remain under Apache 2.0. However, we recommend that you always run the latest version of Unleash, so that you get security patches, bug fixes, and new features. To plan your upgrade to v8, see [Upgrading Unleash](/deploy/upgrading-unleash#upgrading-from-v7-to-v8).
  </Accordion>
</AccordionGroup>

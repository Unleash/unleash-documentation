The App for Slack integration posts a message to your Slack workspace when something changes in Unleash, such as when someone enables a feature flag, adds a strategy, or creates a change request. Each message describes the change, for example who enabled a feature flag and in which environment and project, and includes an **Open in Unleash** button that takes you from Slack to Unleash.

You choose which [events](#events) trigger a message and which channels receive it. The channels can be public or private. You can also notify additional channels for individual feature flags by using [Slack tags](#tags).

## Installation

The installation steps depend on your Unleash version.

<Tabs>
<Tab title="v8.4 and later">

<span data-badge-type="availability" title="Beta" class="fern-docs-badge large blue subtle rounded-full">Beta</span>

To install the App for Slack integration, follow these steps:

1. In the Unleash Admin UI, go to **Configure > Integrations**.
2. For the App for Slack integration, click **Configure**.
3. Click **Install & connect**.
4. On the **Connect Slack to this Unleash?** page, check that the address shown is the address of your Unleash instance, and then click **Continue to Slack**.
5. If Slack prompts you to sign in, sign in to your Slack workspace.
6. In the **Where do you want to use Unleash Feature Flags?** list, select the workspace where you want to install the app, and then click **Allow**. Slack redirects you back to Unleash, which saves the integration with its access token and opens it for editing.
7. In the **Events** list, select the [events](#events) that you want to be notified about.
8. Optional: In the **Channels** field, enter a comma-separated list of [channels](#parameters) to post the events to.
9. Click **Update**.

If **Install & connect** opens a new tab that shows an access token after you install the app, follow the steps for earlier versions.

</Tab>
<Tab title="Earlier than v8.4">

To install the App for Slack integration by copying the access token to Unleash manually, follow these steps:

1. In the Unleash Admin UI, go to **Configure > Integrations**.
2. For the App for Slack integration, click **Configure**.
3. Click **Install & connect**. Slack opens in a new tab.
4. If Slack prompts you to sign in, sign in to your Slack workspace.
5. Select the workspace where you want to install the app, and then click **Allow**. Slack redirects you to a page that shows your access token.
6. Copy the access token.
7. In Unleash, in the **Access token** field of the integration form, paste the access token.
8. In the **Events** list, select the [events](#events) that you want to be notified about.
9. Optional: In the **Channels** field, enter a comma-separated list of [channels](#parameters) to post the events to.
10. Click **Create**.

</Tab>
</Tabs>

By default, the Unleash App for Slack has access to public channels. To post messages to a private channel, invite the app to that channel.

## Configuration

When you configure the integration, you choose which events to be notified about, which channels to post them to, and whether to filter events by project and environment.

#### Parameters

The App for Slack integration takes the following parameters:

<ParamField path="Access token" type="string" required={true}>
  The token that Unleash uses to post messages to your Slack workspace. In v8.4 and later, Unleash sets the access token when Slack redirects you back after [installation](#installation). In versions earlier than v8.4, you copy the access token from the installation page and paste it into this field.
</ParamField>

<ParamField path="Channels" type="string">
  A comma-separated list of channels to post the configured events to, for example `general, releases`. These channels are always notified, regardless of the event type or the presence of [Slack tags](#tags).
</ParamField>

#### Projects and environments

You can filter which [projects](/concepts/projects) and [environments](/concepts/environments) the integration receives events from. If you don't select any projects or environments, the integration receives events from all of them. Global events that aren't specific to an environment are always received.

## Tags

In addition to the configured channels, you can notify other channels by adding tags of the `slack` type to your feature flags. For example, to send notifications to the `#general` channel, add a `slack` tag with the value `general` or `#general` to the flag. Any configured event related to that feature flag then notifies the tagged channel as well as the channels configured on the integration.

To use only tags to determine which channels to notify, leave the **Channels** field empty in the integration configuration. Because you can create multiple configurations of the integration, you can combine settings to fit your needs. Before posting a message, Unleash combines the configured and tagged channels for the event and removes duplicates.
